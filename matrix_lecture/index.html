การคูณเมทริกซ์

A(m×n) คูณ B(n×p) ได้ผลลัพธ์ขนาด m×p
จำนวนหลักของ A ต้องเท่ากับจำนวนแถวของ B
สมาชิก C[i][j] = ผลรวมของ A แถว i × B หลัก j

C[i][j] = Σ A[i][k] × B[k][j]
⚠️ A×B ≠ B×A (ไม่สลับที่ได้)

📊 Leontief Input-Output Model

นักเศรษฐศาสตร์ Wassily Leontief (รางวัลโนเบล 1973) ใช้เมทริกซ์วิเคราะห์ว่า อุตสาหกรรมต่างๆ ในระบบเศรษฐกิจ ต้องผลิตเท่าไหร่เพื่อตอบสนองความต้องการ

ถ้า A คือเมทริกซ์ Input-Output และ d คือเวกเตอร์ความต้องการ
ผลผลิตที่ต้องผลิต = (I − A)⁻¹ d

สมมติ 2 อุตสาหกรรม:
A = [0.2 0.3] d = [100]
    [0.4 0.1]      [200]

x = (I − A)⁻¹ d = ผลผลิตที่ต้องผลิต

🏭 จำลองระบบเศรษฐกิจ 2 อุตสาหกรรม

กดปุ่มคำนวณเพื่อดูผลลัพธ์

🔐 Hill Cipher

Hill Cipher เป็นวิธีเข้ารหัสข้อความโดยใช้เมทริกซ์คูณกับตัวอักษร คิดค้นโดย Lester Hill ในปี 1929

ตัวอักษร A-Z จะถูกแทนด้วยตัวเลข 0-25
จากนั้นคูณด้วย Key Matrix แล้ว mod 26

Key Matrix K = [3 3]
                [2 5]

เข้ารหัส: C = K × P (mod 26)
ถอดรหัส: P = K⁻¹ × C (mod 26)

🌐 Google PageRank

อัลกอริทึม PageRank ของ Google ใช้เมทริกซ์ในการจัดอันดับหน้าเว็บ โดยมองว่าลิงก์ระหว่างเว็บเป็น "คะแนนโหวต"

สร้าง Transition Matrix จากลิงก์ แล้วหา Eigenvector ที่สอดคล้องกับ Eigenvalue = 1

r = M × r

M = Transition Matrix
r = เวกเตอร์คะแนน PageRank
ทำซ้ำจนค่า r ลู่เข้า (converge)
กดปุ่มเพื่อจำลองการคำนวณ PageRank
