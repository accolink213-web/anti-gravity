📐 เศษส่วน (Fractions)

พื้นฐาน

แนวคิดหลัก

เศษส่วนคือ "การแบ่ง" — $\frac{a}{b}$ หมายถึงเอาของทั้งหมดมาแบ่งเป็น $b$ ส่วน แล้วหยิบมา $a$ ส่วน

ตัวอย่าง

$\frac{2}{3} + \frac{1}{4} = \frac{8}{12} + \frac{3}{12} = \frac{11}{12}$ หา ค.ร.น. แล้วบวกเศษ
$\frac{a}{b} \times \frac{c}{d} = \frac{ac}{bd}$ คูณเศษกับเศษ ส่วนกับส่วน

🔗 ใช้ตรงไหนจริง?

  • Probability: $P(A) = \frac{\text{จำนวนผลที่ต้องการ}}{\text{จำนวนผลทั้งหมด}}$
  • Finance: อัตราส่วนต่าง ๆ เช่น Sharpe Ratio $= \frac{R_p - R_f}{\sigma_p}$
  • Calculus: สัดส่วนการเปลี่ยนแปลง $\frac{\Delta y}{\Delta x}$

⚡ เลขยกกำลัง (Exponents)

สำคัญมาก

แนวคิดหลัก

$a^n$ = คูณ $a$ ซ้ำ $n$ รอบ — แต่ที่เจ๋งกว่าคือมันอธิบาย การเติบโตแบบทวีคูณ

กฎสำคัญ

$a^m \cdot a^n = a^{m+n}$ กฎการคูณ
$\frac{a^m}{a^n} = a^{m-n}$ กฎการหาร
$(a^m)^n = a^{mn}$ กฎยกกำลังซ้อน
$a^0 = 1$ กำลังศูนย์
$a^{-n} = \frac{1}{a^n}$ กำลังลบ
$a^{1/n} = \sqrt[n]{a}$ กำลังเศษส่วน

🔗 ใช้ตรงไหนจริง?

  • Finance: ดอกเบี้ยทบต้น $A = P(1+r)^t$ — เงินเติบโตแบบ exponential
  • ML: Learning rate decay $\alpha_t = \alpha_0 \cdot \beta^t$
  • Physics: การสลายตัวกัมมันตรังสี $N(t) = N_0 e^{-\lambda t}$

🌟 Log & Exponential — ตัว Boss ของ Phase 0

โผล่ทุกศาสตร์

แนวคิดหลัก

Exponential $e^x$ = "การเติบโตที่อัตราเร็วเท่ากับขนาดปัจจุบัน"
Logarithm $\ln(x)$ = "ตัวกลับ (inverse) ของ exponential" — ถามว่า "ยกกำลังเท่าไหร่ถึงจะได้ค่านี้?"

$\ln(e^x) = x$   และ   $e^{\ln(x)} = x$ สองตัวนี้เป็นคู่ inverse กัน

ตัวอย่าง Intuitive

$e^{0.05 \times 10} = e^{0.5} \approx 1.65$ ดอกเบี้ย 5% ต่อปี เงินจะเพิ่ม 65% ใน 10 ปี (ทบต้นต่อเนื่อง)
$\ln(2) \approx 0.693$ "Rule of 70" — เงินเพิ่มเป็น 2 เท่าเมื่อ rate × time ≈ 0.693

🔗 โผล่ตรงไหนบ้าง?

Quantum $\psi(t) = e^{-iEt/\hbar}$ — wave function evolution
Signal $e^{i\omega t}$ — Fourier basis function
Finance $S_t = S_0 e^{(\mu - \frac{\sigma^2}{2})t + \sigma W_t}$ — GBM
ML $\text{softmax}(x_i) = \frac{e^{x_i}}{\sum e^{x_j}}$
Statistics $\text{Log-likelihood} = \sum \ln P(x_i | \theta)$

🔧 การย้ายข้าง & จัดรูปสมการ

ทักษะพื้นฐาน

แนวคิดหลัก

สมการ = ตาชั่ง — ทำอะไรข้างซ้าย ต้องทำข้างขวาด้วย เป้าหมายคือ "isolate" ตัวแปรที่สนใจ

ตัวอย่าง

$3x + 7 = 22 \implies 3x = 15 \implies x = 5$ ลบ 7 ทั้งสองข้าง แล้วหารด้วย 3
$e^{rt} = 2 \implies rt = \ln(2) \implies t = \frac{\ln(2)}{r}$ ใช้ ln ถอด exponential — หาเวลาที่เงินเพิ่มเป็น 2 เท่า

📈 Slope & Rate of Change

สำคัญมาก

แนวคิดหลัก

Slope (ความชัน) = "เปลี่ยนเร็วแค่ไหน?" — เป็นบันไดขั้นแรกสู่ Calculus

$\text{slope} = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$ อัตราการเปลี่ยนแปลงเฉลี่ย

Intuition

↗ ชันมาก = เปลี่ยนเร็ว (เช่น หุ้นพุ่ง)
→ ราบ = ไม่เปลี่ยน (sideway)
↘ ชันลง = ลดลง (ราคาตก)

🔗 ใช้ตรงไหนจริง?

  • Finance: Return = slope ของ equity curve
  • Physics: ความเร็ว = slope ของตำแหน่ง-เวลา
  • ML: Gradient = slope ในหลายมิติ

Calculus — Core Layer ⭐

Calculus คือ "ภาษาของการเปลี่ยนแปลง" — ทุกอย่างในฟิสิกส์, การเงิน, ML, quantum ใช้ Calculus เป็นรากฐาน ถ้าเข้าใจ Calculus ดี เท่ากับปลดล็อค 80% ของสมการทั้งหมดที่จะเจอ

⚡ Derivative — "เปลี่ยนเร็วแค่ไหน?"

Core

แนวคิดหลัก

Derivative คือ slope ณ จุดหนึ่ง — ไม่ใช่ slope เฉลี่ย แต่คือ "ตอนนี้ เร็วแค่ไหน?"

$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x} = \frac{df}{dx}$ ลิมิตของอัตราการเปลี่ยนแปลง เมื่อ $\Delta x$ เข้าใกล้ 0

กฎการหา Derivative

$\frac{d}{dx}(x^n) = nx^{n-1}$ Power Rule
$\frac{d}{dx}(e^x) = e^x$ $e^x$ คงที่!
$\frac{d}{dx}\ln(x) = \frac{1}{x}$ Log Rule
$\frac{d}{dx}\sin(x) = \cos(x)$ Trig Rule
$(fg)' = f'g + fg'$ Product Rule
$\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$ Chain Rule

ตัวอย่างจริง

$v(t) = \frac{dx}{dt}$ Physics: ความเร็ว = อนุพันธ์ของตำแหน่ง — "ตำแหน่งเปลี่ยนเร็วแค่ไหน?"
$\frac{dP}{dt}$ Finance: ราคาเปลี่ยนเร็วแค่ไหน — momentum ของตลาด
$\nabla_\theta \mathcal{L}(\theta)$ ML: Gradient descent — หา derivative ของ loss เพื่อปรับ model
$\Delta = \frac{\partial V}{\partial S}$ Options: Delta = derivative ของราคา option ต่อราคาหุ้น

∫ Integral — "สะสมอะไรบางอย่าง"

Core

แนวคิดหลัก

Integral คือ การบวกสะสม — เอาชิ้นเล็ก ๆ มาต่อกัน ใน Calculus มันคือ "พื้นที่ใต้กราฟ"

$\int_a^b f(x)\,dx = \text{พื้นที่ใต้ } f(x) \text{ จาก } a \text{ ถึง } b$ Definite Integral = การสะสมจาก a ถึง b

ความสัมพันธ์ Derivative ↔ Integral

$\frac{d}{dx}$ แยกชิ้นส่วน → ดูอัตราเปลี่ยน
⟷
$\int dx$ รวมชิ้นส่วน → ดูผลสะสม
$\int_a^b f'(x)\,dx = f(b) - f(a)$ Fundamental Theorem of Calculus — สะพานเชื่อม derivative กับ integral

🔗 ใช้ตรงไหนจริง?

$P(a \le X \le b) = \int_a^b f(x)\,dx$ Probability: ความน่าจะเป็น = พื้นที่ใต้ PDF
$\mathbb{E}[X] = \int x \cdot f(x)\,dx$ Statistics: ค่าคาดหวัง = ค่าเฉลี่ยถ่วงน้ำหนัก
$W = \int F \cdot dx$ Physics: งาน = สะสมแรงตลอดระยะทาง
$\int_0^T r(t)\,dt$ Finance: Cumulative return ตลอดช่วงเวลา

➡️ Vectors — ลูกศรในอวกาศ

Core

แนวคิดหลัก

Vector = "ทิศทาง + ขนาด" — ไม่ใช่แค่ตัวเลข แต่คือ "ชี้ไปทางไหน แรงแค่ไหน"

$\vec{v} = \begin{pmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{pmatrix}$ — vector ใน $n$ มิติ

Operations สำคัญ

$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$ Dot Product: วัด "ความคล้าย" ของทิศทาง — ใช้ใน ML (cosine similarity)
$\|\vec{v}\| = \sqrt{v_1^2 + v_2^2 + \cdots}$ Norm: ขนาดของ vector — ระยะทาง

📋 Matrix — การแปลงข้อมูล

Core

แนวคิดหลัก

Matrix = "เครื่องจักรแปลง vector" — ใส่ vector เข้าไป ได้ vector ใหม่ออกมา มันยืด หมุน สะท้อน หรือฉายข้อมูล

ตัวอย่าง

$\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 2x \\ 3y \end{pmatrix}$ Matrix นี้ "ยืด" แกน x เป็น 2 เท่า แกน y เป็น 3 เท่า

🔗 ใช้ตรงไหนจริง?

  • ML: Neural network ทุก layer = matrix multiplication: $\vec{y} = W\vec{x} + \vec{b}$
  • Quantum: Operator ทุกตัว = matrix ที่ทำหน้าที่กับ quantum state
  • Finance: Correlation matrix ระหว่างสินทรัพย์
  • Graphics: Rotation, scaling, projection ใน 3D

🌟 Eigenvalues & Eigenvectors — "รูปแบบที่ระบบชอบ"

สำคัญที่สุด

แนวคิดหลัก

เมื่อ matrix $A$ ทำกับ vector $\vec{x}$ แล้ว ทิศทางไม่เปลี่ยน แค่ scale — vector นั้นคือ Eigenvector และค่า scale คือ Eigenvalue

$A\vec{x} = \lambda\vec{x}$ $\vec{x}$ = eigenvector, $\lambda$ = eigenvalue — "ทิศทางที่ระบบรักษาไว้"

Intuition

ลองนึกภาพเขย่ากะทะทราย — ทรายจะจัดตัวเป็นรูปแบบเฉพาะ นั่นคือ "eigenvector" ของการสั่น — รูปแบบที่ระบบ "ชอบ"

🔗 ใช้ตรงไหนจริง?

Quantum $\hat{H}|\psi\rangle = E|\psi\rangle$ — Eigenstate = สถานะที่วัดได้ ค่า $E$ = พลังงาน
ML / PCA Eigenvectors ของ covariance matrix = ทิศทางที่ข้อมูลมีความแปรปรวนมากสุด
Markov Eigenvector ที่ $\lambda=1$ = stationary distribution = สมดุลระยะยาว
Google PageRank = eigenvector ของ web graph matrix
🎯

เป้าหมายสิ้นสุด Phase 3

เห็น $A\vec{x} = \lambda\vec{x}$ แล้วอ่านออกว่า "ระบบนี้มีรูปแบบอะไรที่คงอยู่" — เข้าใจ quantum state, PCA, Markov ได้ทันที

🎲 Random Variable & Distributions

Core

แนวคิดหลัก

Random Variable $X$ = ตัวแปรที่ค่าของมัน "สุ่ม" — ไม่รู้ค่าจริงจนกว่าจะเกิดเหตุการณ์
Distribution = "แผนที่" ของความเป็นไปได้ทั้งหมด

Distributions สำคัญ

Normal (Gaussian)
$f(x) = \frac{1}{\sigma\sqrt{2\pi}}e^{-\frac{(x-\mu)^2}{2\sigma^2}}$
ระฆังคว่ำ — ค่าส่วนใหญ่อยู่ใกล้ค่าเฉลี่ย
Return หุ้น, measurement error, height of people
Poisson
$P(X=k) = \frac{\lambda^k e^{-\lambda}}{k!}$
นับจำนวนเหตุการณ์ในช่วงเวลา
จำนวน trade ต่อนาที, จำนวน photon ที่ detector
Exponential
$f(x) = \lambda e^{-\lambda x}$
เวลาระหว่างเหตุการณ์
เวลาระหว่าง orders, radioactive decay

📊 Expectation & Variance

สำคัญมาก

แนวคิดหลัก

Expectation $\mathbb{E}[X]$ = "ค่าเฉลี่ยในระยะยาว" — ถ้าทำซ้ำ ∞ ครั้ง จะได้ค่านี้
Variance $\text{Var}(X)$ = "กระจายแค่ไหน?" — วัดความ "ไม่แน่นอน"

ตัวอย่าง

$\mathbb{E}[X] = \sum x_i \cdot P(x_i) = \int x \cdot f(x)\,dx$ ค่าเฉลี่ยถ่วงน้ำหนักด้วยความน่าจะเป็น
$\text{Var}(X) = \mathbb{E}[(X - \mu)^2] = \mathbb{E}[X^2] - (\mathbb{E}[X])^2$ ค่าเบี่ยงเบนจากค่าเฉลี่ยยกกำลังสอง

🔗 ใช้ตรงไหนจริง?

  • Finance: Expected return $\mathbb{E}[R]$ vs Risk $\sigma = \sqrt{\text{Var}(R)}$ — Sharpe Ratio ใช้ทั้งคู่
  • Quantum: $\langle \hat{A} \rangle = \langle \psi | \hat{A} | \psi \rangle$ — ค่าคาดหวังของการวัด
  • ML: Loss function = $\mathbb{E}[\mathcal{L}(\theta)]$ — minimize expected error

🧠 Conditional Probability & Bayes

เปลี่ยนวิธีคิด

แนวคิดหลัก

Conditional: $P(A|B)$ = "โอกาสเกิด A ถ้ารู้แล้วว่า B เกิด" — ข้อมูลใหม่เปลี่ยนความน่าจะเป็น!

$P(A|B) = \frac{P(B|A) \cdot P(A)}{P(B)}$ Bayes' Theorem — "อัปเดตความเชื่อเมื่อมีข้อมูลใหม่"

ตัวอย่างจริง

$P(\text{ฝนตก}|\text{เมฆครึ้ม}) \gg P(\text{ฝนตก})$ เห็นเมฆครึ้ม → โอกาสฝนเพิ่มขึ้น — ข้อมูลเปลี่ยนความเชื่อ
$P(\text{หุ้นขึ้น}|\text{Fed ลดดอกเบี้ย})$ การคิดแบบ trader — ทุก event update ความน่าจะเป็น
🎯

เป้าหมายสิ้นสุด Phase 4

เริ่มคิดแบบ probabilistic — แทนที่จะพูดว่า "ขึ้นแน่/ลงแน่" เป็น "โอกาสสูงกว่า, expected value เท่าไหร่, risk เท่าไหร่"

Phase 5

Differential Equations — จุดเริ่มอ่าน Physics/Quant จริง

⏱ 1–2 เดือน 🎯 ระบบที่ evolve ตามกฎ

Differential Equation (DE) คือ สมการที่อธิบายว่าระบบเปลี่ยนแปลงอย่างไร — ไม่ได้บอกคำตอบโดยตรง แต่บอก "กฎ" ของการเปลี่ยนแปลง แล้วเราหาคำตอบจากกฎนั้น

🔄 ODE — สมการของการเปลี่ยนแปลง

Gateway

ตัวอย่างพื้นฐานที่สุด

$\frac{dx}{dt} = ax$ "ระบบโตตามค่าปัจจุบัน" → คำตอบคือ $x(t) = x_0 e^{at}$

ถ้า $a > 0$: โตแบบ exponential (ประชากร, ดอกเบี้ย)
ถ้า $a < 0$: สลาย exponential (กัมมันตรังสี, ยาในเลือด)

DE ที่สำคัญในแต่ละศาสตร์

$\frac{d^2x}{dt^2} = -\omega^2 x$ Harmonic Oscillator: ระบบแกว่งไปมา → $x(t) = A\cos(\omega t + \phi)$
$\frac{\partial u}{\partial t} = c^2 \frac{\partial^2 u}{\partial x^2}$ Wave Equation: คลื่นแพร่กระจาย — เสียง, แสง, quantum wave
$i\hbar\frac{\partial}{\partial t}\Psi = \hat{H}\Psi$ Schrödinger Equation: กฎการ evolve ของ quantum state!
$\frac{dS}{S} = \mu\,dt + \sigma\,dW_t$ GBM: ราคาหุ้นเปลี่ยนตามแนวโน้ม + noise
🎯

เป้าหมายสิ้นสุด Phase 5

เห็น DE แล้วอ่านได้ว่า "ระบบนี้ evolve อย่างไร" — Wave equation, Schrödinger, Black-Scholes จะดู familiar ขึ้นมาก

Phase 6

Multivariable Calculus — หลายตัวแปร

⏱ 1–2 เดือน 🎯 Optimization & Gradient

โลกจริงมีหลายตัวแปร — ราคาหุ้นขึ้นกับ 100 ปัจจัย, neural network มีล้าน parameter Multivariable Calculus คือเครื่องมือจัดการ "การเปลี่ยนแปลงในหลายมิติ"

📐 Partial Derivatives

Core

แนวคิดหลัก

Partial derivative $\frac{\partial f}{\partial x}$ = "เปลี่ยน $x$ อย่างเดียว ตัวอื่นตรึงไว้ ดูว่า $f$ เปลี่ยนแค่ไหน"

$f(x,y) = x^2y + 3y \implies \frac{\partial f}{\partial x} = 2xy, \quad \frac{\partial f}{\partial y} = x^2 + 3$

🧭 Gradient — "ทิศทางที่ขึ้นเร็วสุด"

ตัว Boss

แนวคิดหลัก

Gradient = vector ของ partial derivatives ทุกตัว — ชี้ไปทาง "ฟังก์ชันเพิ่มเร็วที่สุด"

$\nabla f(x,y) = \begin{pmatrix} \frac{\partial f}{\partial x} \\ \frac{\partial f}{\partial y} \end{pmatrix}$ "ลูกศร" ชี้ทางขึ้นเขาเร็วสุด — ถ้าอยากลง ก็ไปทางตรงข้าม

🔗 ใช้ตรงไหนจริง?

ML Gradient Descent: $\theta_{t+1} = \theta_t - \alpha \nabla_\theta \mathcal{L}$ — ปรับ model ไปทาง error ลดเร็วสุด
Optimization หาจุดต่ำสุด/สูงสุดของฟังก์ชันหลายตัวแปร
Physics $\vec{F} = -\nabla V$ — แรง = gradient ของพลังงานศักย์ (ชี้ทาง "ลงเขา")
Finance Greeks: $\Delta, \Gamma, \Theta, \mathcal{V}$ = partial derivatives ของราคา option

📦 Multiple Integrals & Line Integrals

Extended

แนวคิดหลัก

เหมือน integral ปกติ แต่สะสมในหลายมิติ — คำนวณปริมาตร, flow, หรือ probability ในหลายตัวแปร

$\iint f(x,y)\,dx\,dy$ ปริมาตรใต้ surface — Probability ใน 2 ตัวแปร
🎯

เป้าหมายสิ้นสุด Phase 6

เห็น $\nabla f$ แล้วรู้ทันทีว่า "ชี้ทางเปลี่ยนเร็วสุด" — เข้าใจ Gradient Descent, Greeks, และ force fields

Phase 7

Stochastic Process — ระบบที่มีความสุ่ม

⏱ 2–3 เดือน 🎯 Quant / Finance Core

ทุกอย่างจนถึงตรงนี้เป็น "deterministic" — ใส่ input รู้ output แน่นอน แต่โลกจริง (ตลาด, ฟิสิกส์ quantum) มี ความสุ่มเป็นส่วนหนึ่งของระบบ Stochastic process คือคณิตศาสตร์สำหรับเรื่องนั้น

🎯 Markov Chains

Foundation

แนวคิดหลัก

"อนาคตขึ้นกับปัจจุบันเท่านั้น ไม่ขึ้นกับอดีต" — Markov property

$P(X_{n+1} = j \mid X_n = i, X_{n-1}, \ldots) = P(X_{n+1} = j \mid X_n = i)$ ไม่ว่าจะเดินทางมาอย่างไร สำคัญแค่ "ตอนนี้อยู่ที่ไหน"

🔗 ใช้ตรงไหนจริง?

  • Finance: Credit rating transitions, regime switching models
  • ML: Hidden Markov Models (speech recognition), MCMC
  • Physics: Random walk, diffusion process

🌊 Brownian Motion — ตัวแม่ของ Randomness

Critical

แนวคิดหลัก

Brownian motion $W_t$ คือ "เดินสุ่มแบบต่อเนื่อง" — ทุก step สุ่ม แต่รวมกันได้เป็น path ต่อเนื่อง

คุณสมบัติ: $W_0 = 0$,   $W_t - W_s \sim \mathcal{N}(0, t-s)$,   increments เป็นอิสระ

⚡ Itô Process & SDE

Quant Core

แนวคิดหลัก

เมื่อรวม แนวโน้ม (drift) กับ ความสุ่ม (diffusion) ได้ Stochastic DE:

$dS_t = \underbrace{\mu S_t\,dt}_{\text{drift (แนวโน้ม)}} + \underbrace{\sigma S_t\,dW_t}_{\text{diffusion (noise)}}$ Geometric Brownian Motion — โมเดลราคาหุ้นพื้นฐาน

Itô's Lemma — Chain Rule ของ Stochastic Calculus

$df = \frac{\partial f}{\partial t}dt + \frac{\partial f}{\partial S}dS + \frac{1}{2}\frac{\partial^2 f}{\partial S^2}(dS)^2$ คล้าย Chain Rule แต่มี "เทอมพิเศษ" $\frac{1}{2}\frac{\partial^2 f}{\partial S^2}\sigma^2 S^2 dt$ เพราะ $(dW_t)^2 = dt$

นี่คือเครื่องมือที่ Black-Scholes ใช้ derive สูตรราคา option!

🎯

เป้าหมายสิ้นสุด Phase 7

เห็น $dS_t = \mu\,dt + \sigma\,dW_t$ แล้ว อ่านออก ว่า "ราคาเปลี่ยนตาม drift + noise" — Black-Scholes, risk-neutral pricing เริ่ม make sense

Phase 8

Functional / Operator Thinking — Quantum จริงจัง

⏱ 2–4 เดือน 🎯 Quantum Mechanics & Beyond

ถึงจุดนี้ เราไม่ได้แค่ "คำนวณ" แต่ คิดเป็นระบบ — Operator ทำหน้าที่กับ function (ไม่ใช่ตัวเลข), Hilbert space คือห้องที่ quantum state อาศัยอยู่, Fourier คือการ "แยกสเปกตรัม" ของสัญญาณ

🏗️ Hilbert Space — ห้องของ Quantum

Foundation

แนวคิดหลัก

Hilbert space = "vector space ที่สมบูรณ์" พร้อม inner product — quantum state ทุกตัวอยู่ในนี้

$\langle \psi | \phi \rangle = \int \psi^*(x)\phi(x)\,dx$ Inner product — วัด "ความทับซ้อน" ระหว่าง 2 quantum states

⚙️ Operators — เครื่องจักรที่ทำกับ Functions

Core Quantum

แนวคิดหลัก

ในคณิตปกติ: function รับ ตัวเลข → คายตัวเลข
ใน quantum: operator รับ function → คาย function
เหมือน matrix แต่ทำงานในมิติอนันต์

Operators สำคัญ

$\hat{p} = -i\hbar\frac{\partial}{\partial x}$ Momentum operator — "วัดโมเมนตัม" = derivative ของ wave function
$\hat{H} = -\frac{\hbar^2}{2m}\frac{\partial^2}{\partial x^2} + V(x)$ Hamiltonian — "พลังงานรวม" = kinetic + potential

🌟 Eigenstate Equation — สมการที่สำคัญที่สุดของ Quantum

จุดหมายปลายทาง
$\hat{H}\psi = E\psi$ Time-independent Schrödinger Equation
"operator พลังงาน ทำกับ state → ได้ state เดิมคูณค่าพลังงาน"

นี่คือ eigenvalue equation เดียวกันกับ $A\vec{x}=\lambda\vec{x}$ ใน Linear Algebra! แค่ตอนนี้ $A$ เป็น operator, $\vec{x}$ เป็น function, $\lambda$ เป็นค่าที่วัดได้

🔗 ตัวอย่างจริง

  • Hydrogen atom: แก้ $\hat{H}\psi = E\psi$ → ได้ energy levels $E_n = -\frac{13.6}{n^2}$ eV
  • Harmonic oscillator: แก้ $\hat{H}\psi = E\psi$ → ได้ $E_n = \hbar\omega(n + \frac{1}{2})$ (พลังงาน quantized!)
  • Matrix mechanics: เขียน operator เป็น matrix → หา eigenvalues ด้วย Linear Algebra ปกติ

🎵 Fourier Intuition — "แยกสเปกตรัม"

Essential

แนวคิดหลัก

Fourier Transform = "แยกสัญญาณออกเป็นคลื่นพื้นฐาน" — เหมือนเอาเสียงดนตรีมาแยกเป็นโน้ตแต่ละตัว

$\hat{f}(\omega) = \int_{-\infty}^{\infty} f(t) e^{-i\omega t}\,dt$ "ถอดรหัส" สัญญาณ: เวลา → ความถี่

🔗 ใช้ตรงไหนจริง?

  • Quantum: Position ↔ Momentum เป็น Fourier pair ($\psi(x) \leftrightarrow \tilde{\psi}(p)$)
  • Signal Processing: แยกสัญญาณเสียง, กรอง noise
  • Finance: Characteristic function, spectral analysis ของ returns
  • ML: Fourier features, convolutional layers
🏆

เห็น $\hat{H}\psi = E\psi$ แล้วอ่านออกว่า "Eigenvalue problem ของ energy operator"
เห็น $dS_t = \mu\,dt + \sigma\,dW_t$ แล้วอ่านออกว่า "ราคาเปลี่ยนตาม drift + noise"

สมการไม่ใช่ภาษาเอเลี่ยนอีกต่อไป — มันคือ "ภาษาที่เล่าเรื่องของจักรวาล" 🌌
