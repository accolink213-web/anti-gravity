Linear Algebra — ภาษาของระบบหลายมิติ

⏱ 1–3 เดือน 🎯 เรียนคู่กับ Calculus ได้

ถ้า Calculus คือ "ภาษาของการเปลี่ยนแปลง" Linear Algebra คือ "ภาษาของระบบที่มีหลายตัวแปร" — ทุกครั้งที่มีข้อมูลมากกว่า 1 มิติ Linear Algebra จะเป็นเครื่องมือหลัก

➡️ Vectors — ลูกศรในอวกาศ

Core

แนวคิดหลัก

Vector = "ทิศทาง + ขนาด" — ไม่ใช่แค่ตัวเลข แต่คือ "ชี้ไปทางไหน แรงแค่ไหน"

$\vec{v} = \begin{pmatrix} v_1 \\ v_2 \\ \vdots \\ v_n \end{pmatrix}$ — vector ใน $n$ มิติ

Operations สำคัญ

$\vec{a} \cdot \vec{b} = |\vec{a}||\vec{b}|\cos\theta$ Dot Product: วัด "ความคล้าย" ของทิศทาง — ใช้ใน ML (cosine similarity)
$\|\vec{v}\| = \sqrt{v_1^2 + v_2^2 + \cdots}$ Norm: ขนาดของ vector — ระยะทาง

📋 Matrix — การแปลงข้อมูล

Core

แนวคิดหลัก

Matrix = "เครื่องจักรแปลง vector" — ใส่ vector เข้าไป ได้ vector ใหม่ออกมา มันยืด หมุน สะท้อน หรือฉายข้อมูล

ตัวอย่าง

$\begin{pmatrix} 2 & 0 \\ 0 & 3 \end{pmatrix}\begin{pmatrix} x \\ y \end{pmatrix} = \begin{pmatrix} 2x \\ 3y \end{pmatrix}$ Matrix นี้ "ยืด" แกน x เป็น 2 เท่า แกน y เป็น 3 เท่า

🔗 ใช้ตรงไหนจริง?

  • ML: Neural network ทุก layer = matrix multiplication: $\vec{y} = W\vec{x} + \vec{b}$
  • Quantum: Operator ทุกตัว = matrix ที่ทำหน้าที่กับ quantum state
  • Finance: Correlation matrix ระหว่างสินทรัพย์
  • Graphics: Rotation, scaling, projection ใน 3D

🌟 Eigenvalues & Eigenvectors — "รูปแบบที่ระบบชอบ"

สำคัญที่สุด

แนวคิดหลัก

เมื่อ matrix $A$ ทำกับ vector $\vec{x}$ แล้ว ทิศทางไม่เปลี่ยน แค่ scale — vector นั้นคือ Eigenvector และค่า scale คือ Eigenvalue

$A\vec{x} = \lambda\vec{x}$ $\vec{x}$ = eigenvector, $\lambda$ = eigenvalue — "ทิศทางที่ระบบรักษาไว้"

Intuition

ลองนึกภาพเขย่ากะทะทราย — ทรายจะจัดตัวเป็นรูปแบบเฉพาะ นั่นคือ "eigenvector" ของการสั่น — รูปแบบที่ระบบ "ชอบ"

🔗 ใช้ตรงไหนจริง?

Quantum $\hat{H}|\psi\rangle = E|\psi\rangle$ — Eigenstate = สถานะที่วัดได้ ค่า $E$ = พลังงาน
ML / PCA Eigenvectors ของ covariance matrix = ทิศทางที่ข้อมูลมีความแปรปรวนมากสุด
Markov Eigenvector ที่ $\lambda=1$ = stationary distribution = สมดุลระยะยาว
Google PageRank = eigenvector ของ web graph matrix
🎯

เป้าหมายสิ้นสุด Phase 3

เห็น $A\vec{x} = \lambda\vec{x}$ แล้วอ่านออกว่า "ระบบนี้มีรูปแบบอะไรที่คงอยู่" — เข้าใจ quantum state, PCA, Markov ได้ทันที
