Calculus — Core Layer ⭐

⏱ 2–4 เดือน 🎯 สำคัญที่สุดในทุก Phase

Calculus คือ "ภาษาของการเปลี่ยนแปลง" — ทุกอย่างในฟิสิกส์, การเงิน, ML, quantum ใช้ Calculus เป็นรากฐาน ถ้าเข้าใจ Calculus ดี เท่ากับปลดล็อค 80% ของสมการทั้งหมดที่จะเจอ

⚡ Derivative — "เปลี่ยนเร็วแค่ไหน?"

Core

แนวคิดหลัก

Derivative คือ slope ณ จุดหนึ่ง — ไม่ใช่ slope เฉลี่ย แต่คือ "ตอนนี้ เร็วแค่ไหน?"

$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x} = \frac{df}{dx}$ ลิมิตของอัตราการเปลี่ยนแปลง เมื่อ $\Delta x$ เข้าใกล้ 0

กฎการหา Derivative

$\frac{d}{dx}(x^n) = nx^{n-1}$ Power Rule
$\frac{d}{dx}(e^x) = e^x$ $e^x$ คงที่!
$\frac{d}{dx}\ln(x) = \frac{1}{x}$ Log Rule
$\frac{d}{dx}\sin(x) = \cos(x)$ Trig Rule
$(fg)' = f'g + fg'$ Product Rule
$\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)$ Chain Rule

ตัวอย่างจริง

$v(t) = \frac{dx}{dt}$ Physics: ความเร็ว = อนุพันธ์ของตำแหน่ง — "ตำแหน่งเปลี่ยนเร็วแค่ไหน?"
$\frac{dP}{dt}$ Finance: ราคาเปลี่ยนเร็วแค่ไหน — momentum ของตลาด
$\nabla_\theta \mathcal{L}(\theta)$ ML: Gradient descent — หา derivative ของ loss เพื่อปรับ model
$\Delta = \frac{\partial V}{\partial S}$ Options: Delta = derivative ของราคา option ต่อราคาหุ้น

∫ Integral — "สะสมอะไรบางอย่าง"

Core

แนวคิดหลัก

Integral คือ การบวกสะสม — เอาชิ้นเล็ก ๆ มาต่อกัน ใน Calculus มันคือ "พื้นที่ใต้กราฟ"

$\int_a^b f(x)\,dx = \text{พื้นที่ใต้ } f(x) \text{ จาก } a \text{ ถึง } b$ Definite Integral = การสะสมจาก a ถึง b

ความสัมพันธ์ Derivative ↔ Integral

$\frac{d}{dx}$ แยกชิ้นส่วน → ดูอัตราเปลี่ยน
⟷
$\int dx$ รวมชิ้นส่วน → ดูผลสะสม
$\int_a^b f'(x)\,dx = f(b) - f(a)$ Fundamental Theorem of Calculus — สะพานเชื่อม derivative กับ integral

🔗 ใช้ตรงไหนจริง?

$P(a \le X \le b) = \int_a^b f(x)\,dx$ Probability: ความน่าจะเป็น = พื้นที่ใต้ PDF
$\mathbb{E}[X] = \int x \cdot f(x)\,dx$ Statistics: ค่าคาดหวัง = ค่าเฉลี่ยถ่วงน้ำหนัก
$W = \int F \cdot dx$ Physics: งาน = สะสมแรงตลอดระยะทาง
$\int_0^T r(t)\,dt$ Finance: Cumulative return ตลอดช่วงเวลา
🎯

เป้าหมายสิ้นสุด Phase 2

เห็น Differential equation แล้ว ไม่ panic — รู้ว่า $\frac{dx}{dt}$ คือ "อัตราเปลี่ยน" และ $\int$ คือ "สะสม"
