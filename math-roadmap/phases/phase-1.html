ฟังก์ชัน + Graph Intuition

⏱ 1–2 เดือน 🎯 จุดที่คนข้ามแล้วพังหนัก

ฟังก์ชันคือ "เครื่องจักรที่รับ input แล้วพ่น output" — ถ้าเข้าใจฟังก์ชันเป็นภาพ (กราฟ) ไม่ใช่แค่สูตร คุณจะ "เห็น" พฤติกรรมของระบบได้ Quantum และ Quant เต็มไปด้วย ฟังก์ชันที่กำลัง evolve

📊 Function คืออะไร?

Core Concept

แนวคิดหลัก

$f(x)$ = กล่องดำที่รับค่า $x$ แล้วให้ค่า $f(x)$ กลับมา — ทุก input มี output เดียว

กราฟคือ "ภาพ" ของฟังก์ชัน — แกน $x$ คือ input, แกน $y$ คือ output

ฟังก์ชันสำคัญที่ต้องรู้จัก

$y = ax + b$
Linear
เส้นตรง — เปลี่ยนด้วยอัตราคงที่
ค่าแท็กซี่: ค่าเริ่ม + (ราคา × ระยะทาง)
$y = x^2$
Quadratic
โค้ง U — ยิ่งไปยิ่งเร็ว
พลังงานจลน์ $KE = \frac{1}{2}mv^2$
$y = e^x$
Exponential
ระเบิด! — โตตามขนาดตัวเอง
การแพร่กระจายไวรัส, ดอกเบี้ยทบต้น
$y = \ln(x)$
Logarithmic
โตเร็วตอนแรก แล้วช้าลงเรื่อย ๆ
การรับรู้ของมนุษย์ (Weber-Fechner law)
$y = \sin(x)$
Sinusoidal
แกว่งไปมา — คลื่น!
คลื่นเสียง, ไฟ AC, quantum wave
$y = \frac{1}{x}$
Hyperbolic
ยิ่งเยอะ ยิ่งได้น้อย
Diminishing returns, กฎอุปสงค์

📈 Slope & Rate of Change

สำคัญมาก

แนวคิดหลัก

Slope (ความชัน) = "เปลี่ยนเร็วแค่ไหน?" — เป็นบันไดขั้นแรกสู่ Calculus

$\text{slope} = \frac{\Delta y}{\Delta x} = \frac{y_2 - y_1}{x_2 - x_1}$ อัตราการเปลี่ยนแปลงเฉลี่ย

Intuition

↗ ชันมาก = เปลี่ยนเร็ว (เช่น หุ้นพุ่ง)
→ ราบ = ไม่เปลี่ยน (sideway)
↘ ชันลง = ลดลง (ราคาตก)

🔗 ใช้ตรงไหนจริง?

  • Finance: Return = slope ของ equity curve
  • Physics: ความเร็ว = slope ของตำแหน่ง-เวลา
  • ML: Gradient = slope ในหลายมิติ
